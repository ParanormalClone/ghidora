# Dashboard Application

A minimal Flask dashboard application.

## Setup

1. Create virtual environment:
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Run the application:
```bash
python dashboard.py
```

## Repository Structure

This repository contains only the essential files:
- `dashboard.py` - Main application file
- `requirements.txt` - Python dependencies
- `README.md` - This file

All other files (virtual environment, static files, templates, test files) are excluded via .gitignore to keep the repository size minimal.
